Image Studio 2.0.3 adds desktop update notifications across the whole app, including PhotoCraft and Krita.

- Check for new stable releases at startup and every six hours, even before the image engine is set up.
- See an **Update available** popup with **Download update**, **Release notes**, and **Later**. Download opens the official installer in your browser. Close Image Studio and run it when you are ready; saved projects, pictures, models and settings remain in place.
- Later defers reminders for that version for one day. Automatic popups wait while the app is busy or in the background.
- **Settings → This PC → App updates** shows your installed version, the last successful check, a **Check for updates** button and an automatic-check switch. Manual checks can reopen an update you deferred.
- Offline and rate-limited checks show a useful message in Settings without an automatic error popup. Drafts, prereleases, older versions and releases without a matching installer are not offered for download. Microsoft Store builds leave updating to the Store.
- The website refreshes its cached release information on page load so the download buttons pick up new installers promptly.

Install this version manually once if you have 2.0.2 or earlier. Future published versions can trigger the update popup.

The PhotoCraft flat-blue shadow-lift limitation documented in the 2.0.2 release remains unchanged.

Validation: 193 update, project, layers, workspace, pipeline, desktop and packaging checks passed. The startup popup, Later, manual reopening and installer link were verified against real published GitHub release data with the image engine stopped. Website and frontend TypeScript builds passed; a browser check verified all three download buttons refresh a cached older release through a single shared request.
