# Image Studio 2.0.1

Combine multiple pictures in PhotoCraft and Krita without losing the background.

- **Add image layers:** open a background, then choose **Add images…** in PhotoCraft or **Add images as layers…** in Krita. Select several files together, or drop them onto an open canvas. Each image becomes a named layer, with transparency preserved, centered and reduced to fit when needed. Import up to 16 images totaling 100 MB per batch.
- **Position your overlays:** PhotoCraft's selected-layer Inspector now includes **Move / resize…**. Batch imports create one undoable revision, and PSD/PCraft exports retain the layers. PhotoCraft can also open several files together, with the first as the background.
- **Krita integration:** image layers go into the current canvas. A changed canvas or an active AI edit is reported instead of placing images into the wrong document. After updating, close Krita and reopen it from Image Studio to refresh its AI panel.
- **Editing controls:** includes the pending desktop control refinements, clearer adjustment and pipeline settings, and updated website descriptions.
- **Camera development:** preserves brightness during white-balance correction, lifts dark files through exposure while retaining deep shadows, and checks noise reduction using detail at the camera's resolution.
- **Clean-install startup:** the desktop window can read its pipeline catalog before the engine's image-processing libraries have been installed.

Download **ImageStudio-2.0.1-Setup.exe** below and run it to update an existing installation. Your models, saved pictures and settings stay in their existing folders.

The Windows installer is not code-signed yet. Windows SmartScreen may ask for **More info → Run anyway**. No Linux build is included in this release.
