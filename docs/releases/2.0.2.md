Image Studio 2.0.2 adds a project workflow to both PhotoCraft and Krita.

- Start at a project home; create named projects, reopen saved work, rename, close, or start a new project.
- Import several images into a source-image bin without changing the canvas. Choose original-size placement, fit, or a new canvas explicitly. Drag images onto the canvas, move them, and resize with corner handles.
- Clear the canvas while keeping source images. Undo the clear in PhotoCraft or restore a saved native checkpoint in Krita.
- Save portable `.istudio` files containing the document, originals and editing history/checkpoints. PhotoCraft projects live outside the disposable cache; older workspaces migrate on first open.
- Krita saves native `.kra` documents, keeps layers/masks/color depth, autosaves managed documents, and confirms saves before reporting success or closing. Autosave is paused while creating temporary arrangement previews.
- Apply a PhotoCraft Assistant request in one action, with optional plan review. Requests needing clarification still stop for a choice.
- Fix marked-area filters failing when PhotoCraft had already cleared the selection. Preserve phone-photo orientation when placing images in Krita.

After upgrading, close Krita and reopen it from Image Studio once to load the updated plugin.
