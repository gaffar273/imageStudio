Windows installation troubleshooting

Choose the message that matches what you see when downloading or opening an AGS Labs installer on Windows 11.

Edge says the file isn’t commonly downloaded

Open Downloads in Edge with Ctrl + J and read the full message. A new installer can have little download history. Start from the product’s official download page and match the filename and version. When Edge offers Keep for an uncommon download, save the file and check its hash before opening it.

GlideYT downloads · Image Studio release

Check the installer you downloaded

Open the folder containing the installer, right-click an empty area and choose Open in Terminal. In PowerShell, run the command below. For Image Studio, substitute its actual installer filename.

Get-FileHash -Algorithm SHA256 ".\GlideYT-Setup.exe"

For the current GlideYT installer from this site, the SHA-256 value is 2c0d85b9da9d5685d351d80465d3410f574be5cd147e95395202c83339e163c5. For Image Studio, compare the value with the asset hash on GitHub. A match confirms you received the published file. If they differ, discard the file and download it again from the official release.

SmartScreen says “Windows protected your PC”

Choose More info to see the filename and publisher. The current GlideYT Windows installer is unsigned, so Windows can display “Unknown publisher.” If you trust the source, have checked the hash, and Windows offers Run anyway, that choice applies to this launch. Managed PCs may require IT approval.

Microsoft’s guide to SmartScreen reputation

Smart App Control blocked the installer

Open Windows Security → App & browser control → Smart App Control settings to confirm which protection produced the block. Smart App Control has no per-app exception. Keep it enabled and report the block to AGS Labs with the release version. On a work or school device, contact your administrator for an approved installation.

Microsoft’s Smart App Control FAQ

Defender reports a threat, or Edge marks the file unsafe

Stop the installation and leave any quarantined file in place. Open Windows Security → Virus & threat protection → Protection history for the detection name. Include it and the release URL in your report so we can investigate the specific file.

Contact product support

Include the app version, Windows version, exact warning and whether it appeared in Edge, when opening the file, or during setup. Remove personal details from screenshots.
